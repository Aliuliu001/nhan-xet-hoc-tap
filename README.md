## Form 3 phần

**1. Từ vựng** (1 đoạn):
> % hình ảnh → đánh giá phát âm → % cách viết từ → lý do cụ thể

- % hình ảnh = % từ vựng trong bài kiểm tra
- % cách viết từ = trung bình(% từ vựng, % kỹ năng viết), làm tròn 5

**2. Skills** (mỗi kỹ năng 1 đoạn riêng, có % + giải thích *tại sao*):
> Kỹ năng nói · Kỹ năng nghe · Kỹ năng đọc · Kỹ năng viết · Ngữ pháp

**3. Nhận xét chung** (dài, cá nhân hóa):
> điểm mạnh → vấn đề → nguyên nhân → xu hướng → lời khuyên cho con

Đoạn `Kính nhờ quý Phụ Huynh …` **chỉ dùng cho bé giảm nhiều ở 2-3 kỹ năng**.

## Tuyệt đối không được

- Chữ "thầy" / "cô" → dùng "con"
- Chữ "soát bài" → dùng "kiểm tra"
- Số câu đúng/tổng số câu (chỉ hiện %)
- Điểm nói dạng X/10 → chỉ hiện %
- So sánh % với tháng trước
- Nhầm tên bé (trùng tên → hỏi thầy đặt tên gọi riêng)
- Lặp lại cấu trúc câu y hệt giữa các bé

## Dữ liệu cần có mỗi tháng

1. Điểm: bài KT giấy, bài KT nói, % từ vựng/nghe/đọc/viết/ngữ pháp/tổng
2. Ghi chú cá nhân từng bé: tính cách, thái độ, vấn đề riêng
